# Application Guidelines

Work in this package or exact assigned child; inherit root instructions. Own existing-SDK facilitator configuration, metadata-preserving MCP integration, official AppBridge host, theme wiring and stable Telnyx browser SDK surfaces. FastMCP remains the server and full Python client framework.

Read `docs/architecture/VERIFIED_DECISIONS.md` first. The tested path uses native AI SDK ToolLoopAgent and its MCP adapter for the application agent, then official `@modelcontextprotocol/ext-apps` AppBridge/reference sandbox for rendering the unchanged Prefab resource. Do not depend on the rejected Pydantic normalized result path, undocumented Telnyx Assistant Chat UI events, or the tested experimental React renderer's restrictive asset CSP.

Read installed public `.d.ts`/exports and bundled docs for every prop/import. `docs/reference/ai-sdk/`, `mcp-apps/`, `prefab/`, `telnyx/sdk/` and `contracts/FAST_MCP_AND_UI.md` are the local references. The verified released UI message metadata is `toolMetadata.app`; a live doc's older `toolMetadata.mcp.app` example is not the release contract. Keep resource URI/MIME/CSP and actual structured output intact.

Use SDK-owned model loops and official host lifecycle/protocol methods. Integrator supplies user connection and design tokens. Application policy/user validation remains on the trusted backend. No long-lived account key in generated code/browser bundles. Test host denial and teardown; do not manufacture media support by dropping CSP or iframe isolation. Scripts/build commands must be those in this package's real manifest once created.

## Assigned directory
Project target: `packages/app/src/mcp`. Change into this directory before development. This copy is a planning template; the project scaffold is not installed until the worker applies it.
