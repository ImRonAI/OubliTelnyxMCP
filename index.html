01 / Section

What we are building

A bring-your-own-key communications and AI workspace for oubliai.com. The same account-scoped tools serve an external MCP agent, our facilitator, and human interactions inside another application. The product includes phone/SIP/WebRTC, SMS/MMS/WhatsApp/RCS, first-class e-fax and email, video, external-platform meeting bots, AI agents/voice/inference/fine-tuning/RAG, and storage.

App Human workspace, native-agent facilitator and generated domain views FastMCPApp, GenerativeUI, Prefab, native Telnyx Assistant
03 / Section

Architectural boundaries

No duplicate REST executor, custom discovery engine, handwritten agent tool loop, new iframe protocol or replacement queue. The full catalog is accounted for, but special endpoints remain registered-disabled until their actual adapter is validated. At most four tools are model-visible by default; direct authenticated app/client calls do not need an expanded listing.

05 / Section

Decisions already made

  • Domain: oubliai.com; proposed deployment contract is https://oubliai.com/mcp.
  • BYOK and OAuth entry paths; Code Mode on; no default proxy to Telnyx's existing MCP.
  • Four model tools: search, get_schema, execute and directly advertised generate_prefab_ui.
  • Existing meeting platforms only; no bot inside Telnyx Rooms.
  • Store means catalog UI plus the requested account-owned KV document adapter.
  • One integrated workspace, not many separately deployed applications.
06 / Section

The implementation is not underway

This dossier describes future code, future tests and explicit compatibility gates. The existing native framework composition was tested locally without network calls; the actual Telnyx product and facilitator UI delivery have not been claimed complete. Open the Transparency chapter before interpreting any planned capability as a guarantee.
