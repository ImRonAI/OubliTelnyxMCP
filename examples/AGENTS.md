# Directory Scope

This directory groups the named ownership boundaries below it. Read the root `AGENTS.md` and the assigned child guide, then change into the actual child working directory. Do not implement functionality in this container merely to create an entry point.

Canonical contracts are in `docs/reference/SOURCE_INDEX.md`; selected versions and known integration rejections are in `docs/architecture/VERIFIED_DECISIONS.md`. Product package names and directory paths are project organization, not SDK API names. A directory scaffold is not an implemented package.

## Assigned directory
Project target: `examples`. Change into this directory before development. This copy is a planning template; the project scaffold is not installed until the worker applies it.
